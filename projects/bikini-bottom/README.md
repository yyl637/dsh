# 比奇堡 · 抓水母大作战

派大星在海里撒腿狂奔，海绵宝宝扒在他背上（一手搂脖子、一手举长柄网），
一路冲进水母田兜水母。向「鹈鹕骑自行车」benchmark 致敬的纯手写 SVG 动画。

## 文件
- `index.html` —— 全部内容：内联 SVG + 原生 JS，零依赖、可离线双击打开
- `bikini-clip.mp4` —— 1280×720 / 30fps / 10s 演示片段（标题卡片模式）
- `preview.png` —— 单帧预览

## 玩法
- 点画面 / 按 `S` / 点「挥网」→ 海绵宝宝挥网捞水母
- `空格` → 暂停 / 继续
- 「1.0×」按钮 → 切换 1.0× / 1.75× / 0.55× 速度
- 网口靠近水母时会自动兜住，右上角计数 +1

## 实现要点
- 1200×675 的 `viewBox`，三层视差（远景 / 中景 / 地面）各 1600 宽无缝循环
- 派大星的两条腿和两条手臂用两段式 IK 反解关节，配合身体起伏做小跑循环
- 水母、气泡、沙尘、火花、速度线均为 JS 粒子，每帧更新 transform
- 干净录制模式：`index.html?clean=1`（满屏、隐藏按钮）
